--MODUL 2 JAVA OOP --
OOP adalah paradigma pemrograman yang berfokus pada objek dan kelas. OOP memungkinkan pengembang untuk membuat program yang lebih modular, fleksibel, dan mudah dipelihara dengan menggunakan konsep seperti class, object, inheritance, polymorphism, dan encapsulation.
1. Class: Class adalah blueprint atau template untuk membuat objek. Class mendefinisikan atribut (variabel) dan metode (fungsi) yang dimiliki oleh objek yang dibuat dari class tersebut.
 - metadata class adalah informasi tentang class, seperti nama class, atribut, metode, dan hubungan dengan class lain. Metadata class digunakan oleh compiler dan runtime untuk mengelola objek dan menjalankan program.
  -internal structure class adalah struktur data yang digunakan untuk menyimpan informasi tentang class, seperti nama class, atribut, metode, dan hubungan dengan class lain. Internal structure class digunakan oleh compiler dan runtime untuk mengelola objek dan menjalankan program. Internal structure class juga dapat digunakan oleh pengembang untuk memahami bagaimana class bekerja dan bagaimana objek dibuat dari class tersebut.
  -hirearki class adalah hubungan antara class yang menunjukkan bahwa satu class adalah subclass atau child class dari class lain. Hierarki class digunakan untuk mengorganisir class dalam sebuah program dan memungkinkan pengembang untuk menggunakan inheritance untuk mengurangi duplikasi kode. Hierarki class juga dapat digunakan untuk memahami hubungan antara class dan bagaimana objek dibuat dari class tersebut.
  -runtime class adalah class yang digunakan oleh runtime untuk mengelola objek dan menjalankan program. Runtime class menyediakan informasi tentang class, seperti nama class, atribut, metode, dan hubungan dengan class lain. Runtime class juga digunakan oleh runtime untuk mengelola objek dan menjalankan program, serta untuk melakukan refleksi pada class dan objek. Runtime class dapat digunakan oleh pengembang untuk memahami bagaimana class bekerja dan bagaimana objek dibuat dari class tersebut.
- compiled class adalah class yang telah dikompilasi menjadi bytecode yang dapat dijalankan oleh Java Virtual Machine (JVM). Compiled class berisi informasi tentang class, seperti nama class, atribut, metode, dan hubungan dengan class lain. Compiled class digunakan oleh JVM untuk menjalankan program dan mengelola objek yang dibuat dari class tersebut. Compiled class juga dapat digunakan oleh pengembang untuk memahami bagaimana class bekerja dan bagaimana objek dibuat dari class tersebut.


2. Object: Object adalah instance dari class. Object memiliki atribut dan metode yang didefinisikan dalam class. Setiap object dapat memiliki nilai atribut yang berbeda dan dapat memanggil metode yang sama dengan cara yang berbeda.
3. Inheritance: Inheritance adalah konsep di mana sebuah class dapat mewarisi atribut dan metode dari class lain. Class yang mewarisi disebut subclass atau child class, sedangkan class yang diwarisi disebut superclass atau parent class. Inheritance memungkinkan pengembang untuk membuat hierarki class dan mengurangi duplikasi kode.
4. Polymorphism: Polymorphism adalah konsep di mana objek dari class yang berbeda dapat diperlakukan sebagai objek dari class yang sama. Polymorphism memungkinkan pengembang untuk menggunakan metode yang sama pada objek yang berbeda, sehingga meningkatkan fleksibilitas dan keterbacaan kode.
5. Encapsulation: Encapsulation adalah konsep di mana data (atribut) dan metode yang mengoperasikan data tersebut dibungkus dalam satu unit (class) dan disembunyikan dari akses langsung oleh objek lain. Encapsulation memungkinkan pengembang untuk melindungi data dan memastikan bahwa hanya metode yang diizinkan yang dapat mengakses atau memodifikasi data tersebut. Encapsulation juga membantu dalam menjaga integritas data dan meningkatkan keamanan program.
